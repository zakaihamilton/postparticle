# Welcome page imagery

The welcome page uses fictional editorial photographs generated with the built-in imagegen tool. These are demonstration assets, not photographs of a customer, real project, or named location. The video thumbnail is a sample cover image; no video file is implied or included.

Assets are bundled in `public/images/welcome/` as 1536 × 1024 WebP files at quality 82. Next.js `Image` provides responsive delivery. Architecture is reused in the selected article, content library, and website preview to illustrate the publishing connection. The editor image loads eagerly; lower-page imagery loads lazily. No remote image service or Spaces credentials are required.
